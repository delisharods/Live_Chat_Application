# Live Chat Application

A responsive live chat web app built with HTML, CSS and JavaScript, with an AI-powered backend (Node.js + Express + Gemini API).

## Run locally
1. Install Node.js
2. Run `npm install`
3. Create a `.env` file containing: `GEMINI_API_KEY=your-key`
4. Run `npm start`
5. Open http://localhost:3000
